Stability

On this page
  • Public API
  • Experimental features
  • Deprecations
  • Breaking releases
  • Saved formats

This page covers which parts of Riffer you can depend on, how changes to them are announced, and how breaking releases work. Riffer is not at 1.0 yet; the roadmap tracks the path there.

Public API

The public API is everything documented in these guides. You can build on it, and it changes only in the ways this page describes.

Everything else is internal, even when Ruby lets you reach it. That includes classes, methods and constants that appear in the API reference but not in a guide. Internal code can change in any release without notice. At 1.0, every public constant will be documented and everything else marked private.

Experimental features

Experimental features are labelled experimental in the guides, like the prompted structured output strategy. They can change in any minor release, and the CHANGELOG notes each change.

Deprecations

A breaking change to the public API lands first as a new API or an opt-in flag, and the old way prints a deprecation warning. The warning says the old way will be removed in a future version, and it appears for at least one release before that happens.

Breaking releases

Before 1.0, any minor release can include breaking changes, but never without notice: an earlier release deprecates what’s changing first, so you’ll see the warnings before anything breaks. Each breaking release comes with an upgrade guide in UPGRADING.md, and the CHANGELOG lists its changes under ⚠ BREAKING CHANGES.

After 1.0, breaking changes ship only in major versions.

Saved formats

Saved formats are the data Riffer produces for you to store and load later, such as serialized agents and messages persisted with to_h.

  • Riffer can read a new format at least one release before it starts writing it, so a deploy that runs a release alongside the one before it keeps working.
  • Anything saved by a 1.x release loads in every later 1.x release.

See Serialization → Versioning for how agent data records its format version.
