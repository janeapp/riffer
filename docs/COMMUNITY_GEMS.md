# Community Gems

Community gems extend Riffer from outside this repo. Their authors maintain them, not Jane, and the [stability policy](STABILITY.md) doesn't cover them. See [Stability → Packages](STABILITY.md#packages) for which gems Jane maintains and how a gem can join this repo.

## Getting yours listed

Open a pull request that adds your gem to the list above, with a link to its source and a one-line description of what it does.
