# Riffer

The all-in-one Ruby framework for building AI-powered applications and agents.

## Installation

Add to your application's Gemfile:

```ruby
gem "riffer"
```

## Documentation

Guides and the API reference live at [riffer.ai](https://riffer.ai). The source, issue tracker and contributing guide are at [github.com/janeapp/riffer](https://github.com/janeapp/riffer).
